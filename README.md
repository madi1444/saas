# 🏨 Madielle Oteľ — қонақүй бөлмелерін брондау веб қосымшасы

Қонақүй бөлмелерін онлайн брондауға арналған бір беттік сайт. Сервер қажет емес: деректер браузердің `localStorage` жадында сақталады.

## Мүмкіндіктері

- Бос бөлмені күн, қонақ саны және санат бойынша табу
- Бөлмелер карточкалары мен бағалар (Стандарт, Делюкс, Люкс, Семейный, Президенттік)
- Өтінім (брондау) формасы, сома автоматты есептеледі, бөлме бос емес болса ескертеді
- Брондарды нөмірі, аты немесе телефоны бойынша табу; күнді өзгерту, бас тарту, қайта белсендіру
- Брондар тізімі: іздеу, статус (белсенді / белсенді емес), санат, мерзім, күн, сома, қонақ саны, бөлме бойынша сүзу және сұрыптау
- Қонақ сұраныстары (кеш шығу, трансфер, қосымша кереует т.б.)
- Жаңа бөлме қосу және өшіру
- Толық есеп: көрсеткіштер, санат / бөлме / ай бойынша кестелер, брондар тізімі
- Есепті **PDF** (жаңа бетте ашу немесе сақтау) және **Excel** (.xlsx) форматында жүктеу

## Жергілікті іске қосу

`index.html` файлын браузерде ашсаңыз болғаны.

## GitHub Pages арқылы жариялау

1. GitHub-та жаңа репозиторий жасаңыз (мысалы, `madielle-hotel`) және осы файлдарды жүктеңіз.
2. **Settings → Pages** бөліміне өтіңіз.
3. **Build and deployment → Source** ішінде **Deploy from a branch** таңдаңыз.
4. Branch ретінде `main` және `/ (root)` таңдап, **Save** басыңыз.
5. Бір-екі минуттан кейін сайт `https://<аты>.github.io/madielle-hotel/` мекенжайында ашылады.

## Ескертпе

- Деректер әр қолданушының браузерінде сақталады, құрылғылар арасында бөлісілмейді. Ортақ база қажет болса, серверлік бөлік (Node.js, PHP немесе Python) керек.
- PDF және Excel жасау үшін `jsPDF`, `html2canvas` және `SheetJS` кітапханалары cdnjs арқылы жүктеледі, сондықтан интернет қажет.
- Мекенжай, телефон және email мәтіндері мысал ретінде жазылған, `index.html` ішінде өзгертіңіз.
