# ⚡ madiTASKS — файл жүктеу және бағалау қосымшасы

Файл мен папка жүктеп, олардың күйін белгілеп, баға қоюға арналған неон 3D стильді веб-қосымша. Деректер браузердің `localStorage` жадында сақталады.

## ✨ Мүмкіндіктері

- 📤 Файл жүктеу: батырма арқылы немесе файлды тақтаға тартып әкелу арқылы
- 📁 Папка құру және папканың ішіне кіру (жол көрсеткіші бар)
- 🚦 Күйі: **Жаңа**, **Орындалуда**, **Орындалды**
- ⭐ 1-ден 5-ке дейін жұлдыздық баға
- 🌐 Файлды «Ортақ» немесе «Жеке» деп белгілеу
- 🗑️ Файл не папканы жою
- 🧊 Неон 3D дизайн: айналатын куб, сақиналар, еңкейетін карточкалар

## 🛠️ Технологиялар

HTML5, CSS3 (3D transforms, animations), JavaScript (ES5), `localStorage`

## 📂 Жоба құрылымы

```
maditasks/
├── index.html   # бет құрылымы
├── style.css    # неон және 3D дизайн
├── script.js    # жүктеу, папка, күй, баға логикасы
└── README.md    # жоба сипаттамасы
```

## 🚀 Іске қосу

1. Жобаны жүктеп алыңыз немесе клондаңыз:
   ```bash
   git clone https://github.com/madi1444/maditasks.git
   ```
2. `index.html` файлын браузерде ашыңыз. Қосымша орнату қажет емес.

## 🌍 GitHub Pages арқылы жариялау

1. Репозиторийде **Settings → Pages** бөліміне кіріңіз.
2. **Branch** ретінде `main` және `/ (root)` таңдап, **Save** басыңыз.
3. Бір-екі минуттан кейін сайт `https://madi1444.github.io/maditasks/` мекенжайында ашылады.

## ⚠️ Ескерту

Файлдың аты, көлемі, күйі және бағасы ғана сақталады, файлдың өзі сақталмайды. Деректер тек осы браузерде көрінеді. Басқа адамдарға ортақ ету үшін сервер қосу керек.
